# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## Разработка корпоративного сайта IT-компании с CMS-панелью

---

## 1. Общее описание

Одностраничное приложение (SPA) — корпоративный сайт компании, оказывающей IT-услуги
(IT-аутсорсинг, видеонаблюдение, ЛВС/СКС, IP-телефония и др.) для малого и среднего бизнеса.

Сайт полностью управляется через собственную админ-панель (CMS): весь контент, дизайн, SEO,
заявки и чат редактируются без участия программиста.

---

## 2. Технологический стек

- **Frontend:** React + TypeScript + Vite, роутинг react-router-dom, состояние — @tanstack/react-query
- **Стили:** Tailwind CSS + shadcn/ui (компоненты на Radix UI), иконки lucide-react
- **Формы:** react-hook-form + zod
- **Backend:** облачные функции на Python 3.11 (HTTP-эндпоинты)
- **База данных:** PostgreSQL
- **Хранилище файлов:** S3-совместимое
- **Адаптивность:** десктоп / планшет / мобайл; поддержка тёмной и светлой темы

---

## 3. Дизайн-система

- **Стиль:** тёмная тема по умолчанию, «технологичный» неоновый акцент (cyan/бирюза `#00d4ff`),
  стеклянные карточки (glass-card, размытие фона), неоновые бордеры и свечения
- **Шрифты:** заголовки — Oswald, текст — Golos Text
- **Цвета:** заданы через CSS-переменные (HSL) — палитра всего сайта меняется из одного места;
  отдельная палитра для светлой темы
- **Скругления:** базовый радиус 0.75rem
- **Анимации:** появление при скролле, hover-эффекты (magnetic / tilt / spotlight), плавные модалки,
  «плавающие» частицы в hero. Все анимации настраиваются из админки (скорость, тип hover,
  scroll-анимация — глобально и поэлементно)

## 4. Публичная часть — страницы и роуты

| Роут | Страница |
|------|----------|
| `/` | Главная (динамический порядок секций) |
| `/services` | Каталог услуг |
| `/services/:slug` | Страница отдельной услуги |
| `/pricing` | Прайс-лист |
| `/privacy` | Политика конфиденциальности |
| `/admin` | Админ-панель |
| `*` | Страница 404 |

### Секции главной страницы
Порядок и видимость управляются из CMS:

1. **Hero** — заголовок, бейдж, кнопки CTA, статистика
2. **Услуги** — 6 карточек с иконками, кнопкой калькулятора
3. **Почему мы** — 6 карточек преимуществ + метрики
4. **Тарифы** — 3 тарифных плана с фишками
5. **Быстрый заказ** — аккордеон этапов заказа
6. **Проекты** — кейсы с метриками и результатами
7. **Команда** — история компании, состав
8. **Контакты** — телефон, email, адрес, часы работы
9. **FAQ** — аккордеон вопросов-ответов

**Сквозные элементы:** Header (меню с выпадающим списком услуг, переключатель темы, CTA),
Footer, баннер cookie, кнопка «наверх», виджет живого чата.

## 5. Интерактивные модули

- **Форма заявки (ContactModal):** поля имя / телефон (маска +7 (XXX) XXX-XX-XX, валидация 11 цифр) /
  email / услуга / сообщение. Запоминает источник (откуда открыта).
- **Калькулятор IT-услуг:** ползунки, опции, варианты реакции, расчёт стоимости в реальном времени.
- **Калькулятор видеонаблюдения:** типы камер, оборудование, ползунки, расчёт сметы.
- **Живой чат:** виджет с формой (имя, телефон, email, тема обращения), обмен сообщениями через
  polling, интеграция с мессенджером оператора, автосброс при неактивности.

---

## 6. Backend (облачные функции)

1. **cms-api** — центральное хранилище контента: чтение всего контента (публично) и редактирование
   (по токену) — услуги, тарифы, проекты, команда, FAQ, настройки, калькуляторы, меню, анимации,
   история правок с откатами.
2. **auth-api** — авторизация админки: логин/пароль, токены сессий, роли (owner/editor/viewer)
   и права доступа, управление пользователями, первичная установка пароля.
3. **send-email** — приём заявок: сохранение в БД + рассылка на Email (SMTP), в Telegram и в мессенджер Max.
4. **live-chat** — живой чат: сессии, сообщения, вебхуки от оператора, настройки виджета.
5. **seo-api** — управление SEO (метатеги, ключевые слова, аудит).
6. **sitemap** — генерация sitemap.xml.
7. **media-library** — загрузка/удаление медиафайлов (S3).
8. **upload-photo** — загрузка изображений.
9. **secrets-api** — безопасное хранение ключей API (SMTP, токены).
10. **ai-assistant** — ИИ-ассистент.

## 8. Админ-панель (CMS)

Двухэтапная авторизация (логин → пароль), роли и права. Разделы:

- **Аналитика:** Дашборд, Заявки (с счётчиком непрочитанных), Живой чат, История правок (с откатом).
- **Страницы:** редакторы Главной (секции, порядок, видимость), Услуг, Прайса, Политики конфиденциальности.
- **Оформление:** Дизайн (цвета, шрифты, анимации, стиль кнопок/карточек), Визуальный редактор
  (выбор элементов по клику в iframe), Медиабиблиотека, Навигация.
- **Система:** SEO (массовое редактирование метатегов), Пользователи (только owner),
  Секреты API (только owner), Смена пароля.

---

## 9. Интеграции

Email (SMTP), Telegram Bot API, Max (мессенджер) — для заявок и чата.
Все ключи хранятся в защищённом хранилище секретов.

---

## 10. Нефункциональные требования

- Адаптивность (mobile-first), кроссбраузерность.
- SEO: управляемые метатеги, OG-теги, canonical, sitemap.xml, микроразметка Organization.
- Производительность: ленивая загрузка секций, кэширование контента CMS.
- Безопасность: токены сессий, роли/права, отсутствие секретов на фронтенде, отправка данных
  только через backend.
